TrustVault is a secure document-vault demonstration designed around server-enforced permissions, encrypted document storage, and a tamper-evident audit trail.

Open TrustVault applicationExplore features
Deployment note: Sign-in and document operations require the Python/FastAPI backend. Deploy the full project using the included render.yaml. A static Netlify page alone cannot run the API.
🔐

Protected documents

Server-side access checks and encrypted-at-rest document storage help keep files available only to authorized users.

🧾

Audit trail

Security events are linked into a cryptographic chain to help reveal changes to recorded audit entries.

⚡

Revocable access

Permission checks happen on the backend, so access can be withdrawn rather than relying on public file links.
